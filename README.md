# ☕ Chai Menu API – FastAPI Project

## 📌 Project Overview

Chai Menu API is a beginner-friendly REST API project developed using **FastAPI** and Python.

The project manages a chai menu by allowing users to create, view, update, and delete chai items through API endpoints.

This project was developed as part of my hands-on learning journey in FastAPI and backend development.

## 🎯 Project Objectives

- Understand FastAPI fundamentals.
- Learn how REST APIs work.
- Implement CRUD operations.
- Understand HTTP methods and status codes.
- Work with Pydantic models for data validation.
- Explore automatic API documentation using Swagger UI.
- Understand request handling and response models.

## 🛠️ Technologies Used

- Python
- FastAPI
- Uvicorn
- Pydantic
- VS Code
- Swagger UI

## ⚙️ Features

- Add new chai items.
- Retrieve all chai items.
- Retrieve a specific chai item by ID.
- Update existing chai details.
- Delete chai items.
- Validate request data using Pydantic.
- Interactive API documentation.
